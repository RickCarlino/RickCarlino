# Rick Carlino

Co-founder of [Fox.Build](https://fox.build/), former technical co-founder of [FarmBot](https://farm.bot/). Software history enthusiast (1983–2003), Forth fan, and occasional [RetroForth contributor](https://github.com/crcx/retroforth).

## Projects

* ♥️ [KoalaCards](https://Koala.Cards) — language speaking and listening practice.
* ⭐ [Gnutonium](https://github.com/gnutonium/gnutonium) — A *modern* cross-platform Gnutella client for the terminal.
* [Stack Effect](https://github.com/RickCarlino/stack-effect-the-game) — learn Forth stack operations ([play](https://rickcarlino.com/game.html)).
* [Woof Alert](https://github.com/FoxDotBuild/woof-alert) — a dog collar that emails barks.
* [Offline weather station](https://rickcarlino.com/2019/a-weather-station-with-raspberry-pi-and-secure-scuttlebutt.html) — built with Raspberry Pi.
* [Cosmic Conquest](https://github.com/RickCarlino/Cosmic-Conquest-1982) — a revived 1982 sci-fi game.
* [Naivechain TS](https://github.com/RickCarlino/naivechain-ts) — a toy blockchain.
* [Collaborative drawing](https://github.com/RickCarlino/serverside-imagemap-canvas) — using 1990s web technology.
* [RetroForth in the browser](https://rickcarlino.com/retrojs/) — written in TypeScript.
